# مُرشِدي | Murshidi — Final Source Code (v1.0.0)

> منصّة وطنيّة لدعم قرار اختيار التخصّص الجامعي — مقدّمة لجائزة وليّ العهد لأفضل تطبيق خدمات حكوميّة، الدورة الخامسة 2026.
>
> نسخة الـ APK المنشورة (`Murshidi-v1.0.0-release.apk`) بُنيت من هذا السورس بتاريخ 26 نيسان 2026 تحت حزمة `jo.mizan.app`.
> **بعد ذلك التاريخ تغيّر اسم الحزمة إلى `jo.vcoders.murshidi`**، ولم يُعَد بناء الـ APK بعد — لذلك أيّ نسخة جديدة
> تُبنى من هنا ستُثبَّت كتطبيق منفصل بدل أن تحدّث القديم، إلى أن يُعاد إصدار الـ APK.

- **التقنيّات:** React 19 + TypeScript + Vite 8 + TailwindCSS 3 + Recharts + Capacitor 8 (Android API 23 → 35)
- **اللغة:** العربيّة (RTL) مع دعم الإنجليزيّة
- **الحالة:** 13 شاشة كاملة — تعمل بالكامل بدون إنترنت بعد التثبيت

## الشاشات

الترحيب، الرئيسيّة، حاسبة عائد التعليم (ROI)، مقارنة التخصّصات، مرصد سوق العمل، محاكاة القرار،
اختبار الميول (RIASEC)، تجارب الخرّيجين، الاستشارة الذكيّة، وظائف 2030، المنح، المسارات البديلة، الملفّ الشخصي.

## التشغيل السريع

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # بناء إنتاجي إلى dist/
```

## بناء نسخة Android

```bash
npm run android:sync
cd android
./gradlew assembleDebug
```

> ملاحظة: Gradle لا يدعم المسارات بأحرف عربيّة — انسخ المشروع إلى مسار إنجليزي قبل البناء (مثل `C:/murshidi-final/`).

نسخة الـ APK الرسميّة الموقّعة موجودة في صفحة الـ Releases.

## مصادر البيانات

الرقم الوحيد المنسوب إلى مصدر منشور هو بطالة الربع الثاني 2026 من دائرة الإحصاءات العامّة
(نشرة 7 أيلول 2026)، إضافةً إلى أرقام تقرير مستقبل الوظائف 2025 الصادر عن المنتدى الاقتصادي العالمي.
كلّ رقم آخر داخل التطبيق — الرواتب، نسب البطالة لكلّ تخصّص، أعداد إعلانات الوظائف، قيم المنح —
**توضيحي** ويظهر على الشاشة بشارة «مثال توضيحي • ليست بيانات رسمية».
معدّلات القبول المعروضة استرشاديّة وليست الحدود التنافسيّة الرسميّة للقبول الموحّد 2026/2027،
والتي لم تكن قد أُعلنت وقت الكتابة.
