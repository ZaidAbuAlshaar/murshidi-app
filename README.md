# مُرشِدي | Murshidi — Final Source Code (v1.0.0)

> منصّة وطنيّة لدعم قرار اختيار التخصّص الجامعي — مقدّمة لجائزة وليّ العهد لأفضل تطبيق خدمات حكوميّة، الدورة الخامسة 2026.
>
> **هذا هو السورس الحقيقي الذي بُنيت منه نسخة الـ APK النهائيّة** (`Murshidi-v1.0.0-release.apk` — حزمة `jo.mizan.app`)،
> بتاريخ 26 نيسان 2026 — آخر تعديل على الشاشات كان قبل بناء الـ APK بدقائق.

- **التقنيّات:** React 19 + TypeScript + Vite 8 + TailwindCSS 3 + Recharts + Capacitor 8 (Android API 23 → 35)
- **اللغة:** العربيّة (RTL) مع دعم الإنجليزيّة
- **الحالة:** 13 شاشة كاملة — تعمل بالكامل بدون إنترنت بعد التثبيت

## الشاشات

الترحيب، الرئيسيّة، حاسبة عائد التعليم (ROI)، مقارنة التخصّصات، مرصد سوق العمل، محاكاة القرار،
اختبار الميول (RIASEC)، تجارب الخرّيجين، الاستشارة الذكيّة، وظائف 2030، المنح، المسارات البديلة، الملفّ الشخصي.

## التشغيل السريع

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # بناء إنتاجي إلى dist/
```

## بناء نسخة Android

```bash
npm run android:sync
cd android
./gradlew assembleDebug
```

> ملاحظة: Gradle لا يدعم المسارات بأحرف عربيّة — انسخ المشروع إلى مسار إنجليزي قبل البناء (مثل `C:/murshidi-final/`).

نسخة الـ APK الرسميّة الموقّعة موجودة في صفحة الـ Releases.
